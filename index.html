    ABOUT THE DOSSIER

    关于这本志

    它是什么

    一本关于“如果”的档案：如果你只有几千块预算，背囊只装得下这些，而你要在一百零八处没有信号的地方之一，走进去几天。

    怎么玩

    选坐标 → 读简报 → 用固定预算采购 → 在“行军 / 侦察 / 扎营 / 翻找”之间分配体力与物资。每天结束结算饥饿、脱水与失温。

    难度与氛围

    一至二星是郊野与荒径，界面温和、节奏舒缓；四至五星会切到惊悚主题，画面更暗、更吵，事件里出现不该出现的东西。

    支线与彩蛋

    部分事件只在特定装备、特定节点出现。收集隐藏档案会逐步解锁昆仑死亡谷，也会进入异闻录。

    评级

    按推进度、身体状态、剩余物资、彩蛋与伤情综合评分。S 级意味着你几乎把这条线走成了教科书。

    制作

    纯静态单页：原生 JavaScript、内联 SVG 场景、程序化生成的中国地图轮廓。没有引擎、没有素材包、没有联网请求。

    虚构演绎，请勿模仿。真实的无人区不接受试错。
